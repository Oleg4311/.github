# Как внести вклад

Спасибо за интерес! Проекты небольшие, поэтому правила простые.

1. **Сначала issue.** Для нового функционала или крупной правки откройте issue и опишите идею, чтобы не делать лишнюю работу. Опечатки и мелкие исправления можно сразу pull request'ом.
2. **Сообщения коммитов — на английском** в формате `тип: короткое описание` (`feat:`, `fix:`, `docs:`, `test:`, `chore:`, `ci:`).
3. **Тесты.** Исправление ошибки должно сопровождаться тестом, который падал бы без исправления. Проверьте, что `README` описывает команды запуска тестов, и выполните их локально.
4. **Документация и логи — на русском**, как в остальном проекте.
5. **Один pull request — одна тема.** CI должен быть зелёным.

Об уязвимостях сообщайте приватно: вкладка **Security** → **Report a vulnerability** (подробности в `SECURITY.md` каждого репозитория). Публичные issue для этого не используйте.

---

## Contributing (English)

Open an issue before large changes. Commit messages in English (`feat:`, `fix:`, `docs:`, `test:`, `chore:`, `ci:`). A bug fix needs a test that fails without it. One topic per pull request, CI must be green. Report vulnerabilities privately via **Security → Report a vulnerability**.
